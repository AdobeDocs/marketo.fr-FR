# Modèle 2D {#template-2d}

Cliquez avec le bouton droit [télécharger le modèle 2D](https://51837-micrositemarketo.adobeio-static.net/lp-templates/template-2d.html) et sélectionnez **Enregistrer le lien sous...**

>[!NOTE]
>
>Les étapes complètes de téléchargement et d’importation d’un modèle [sont disponibles ici](/help/marketo/product-docs/demand-generation/landing-pages/landing-page-templates/guided-landing-page-template-list.md#how-to-import){target="_blank"}.

![](assets/image2015-6-4-9-3a38-3a47.png)

Ce modèle comprend le contenu suivant :

* En-tête avec logo et bouton (facultatif)
* Une section principale

  * comprend une image d’arrière-plan principale, un en-tête, un slogan, une liste à puces et un formulaire.

* Une section de corps avec texte et sondage (facultatif)
* Pied de page (facultatif)
